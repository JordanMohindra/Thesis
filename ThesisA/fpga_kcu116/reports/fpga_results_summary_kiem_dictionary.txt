KCU116 FPGA HARDWARE RESULTS: DRHE vs LPC, KIEM'S ORIGINAL HUFFMAN TABLE (baseline, 7 Oct 2026)
(The bitstreams now use the re-derived tables: C-sim DRHE 4.21704, LPC 4.40345; board run pending.)
=========================================================================
Board: AMD KCU116 (Kintex UltraScale+ XCKU5P), 100 MHz
Data:  50 ColoRadar frames, 393,216 bytes each (128 range bins x 192 ramps x 4 RX, int16 I/Q)
Setup: FPGA compresses, PC decompresses and checks every frame
Tip:   paste into a monospace font (e.g. Consolas) to keep the columns lined up


1. HEADLINE
-----------
  * Both compressors PASS on all 50 frames
  * Compressed bytes identical to the C simulation on every frame (50/50)
  * Lossless: largest error after decompression = 0
  * DRHE compresses better than LPC on every one of the 50 frames
  * LPC is 5.3x slower and has 230x the latency (it must store the whole frame first)
